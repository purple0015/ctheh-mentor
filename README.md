# CTH Mentor

A minimal AI mentor MVP built with Python, LangChain, Chroma, and FastAPI.

## Structure

- `books/` stores your source PDFs
- `app/` contains ingestion, retrieval, and prompt logic
- `main.py` exposes the FastAPI app
- `requirements.txt` holds Python dependencies

This repository is intentionally scaffolded for the first checkpoint: add one PDF to `books/` and begin building the ingestion pipeline.
